# XFLARE Vector Suite releases

This repository distributes public XFLARE Vector Suite releases. Download the
distribution archive and its `manifest.json` from
[GitHub Releases](https://github.com/xcena-dev/public-xvector-suite/releases).
Each release's manifest records the component versions included in that release.

The distribution contains the XVector and XArithmetic packages and examples,
along with the XCENA Faiss integration source archive. See the selected release's
assets for the available files.

`VERSION_SUITE`, `VERSION_XVECTOR`, `VERSION_XARITH`, and `VERSION_XFAISS` track
versions used by the release workflow. For a specific published release, use its
attached manifest rather than the version files on the default branch, which
may already reflect preparation for a newer release.
